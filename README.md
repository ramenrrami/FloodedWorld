**FloodedWorld** replaces the Air with Water on the world chunks when loaded, wich makes the world flooded.

The spawn checks for the first water block after Y level: ``60``, wich prevents players from spawning at Y level of 250 or higher.

integrated ``/nv``/``/nightvision`` command to get night vision effect.

**WARNING:** the server may crash after entering the Nether for the first time, trough chunk overloading. restarting and rejoin the server **or and** reduce the "Simulation-distance" & "view-distance" in your's server ``server.properties`` file, may fix this.
